# Coal Production & Mining Operations Analytics

## 📌 Project Overview

This project analyzes Indian coal production and mining operations data to
understand production trends, mine-wise and company-wise performance, and
distribution patterns.

The project combines Mining Engineering domain knowledge with Data Analytics
to derive meaningful insights from coal mining data.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Tableau
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization

## 📊 Key Analysis

- State-wise coal production
- Company-wise production
- Mine-wise performance
- Production categories
- Ownership-wise analysis
- Extraction methods
- Coal production and distribution trends

## 📈 Dashboard

The interactive Tableau dashboard provides an overview of India's coal
production and mining operations.




## 🔍 Key Outcomes

- Identified production trends across different states and companies.
- Compared mine-wise and company-wise operational performance.
- Analyzed the distribution of coal production across different categories.
- Used visualization to understand mining operational patterns.

Mining Engineering + Data Analytics
